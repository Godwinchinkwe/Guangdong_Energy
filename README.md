# Guangdong ZJ Energy Co., Ltd. — Website

Rebranded React website for Guangdong ZJ Energy Co., Ltd.

## Stack
- React 18
- React Router 6
- Create React App / react-scripts 5
- Responsive CSS
- English / Chinese language switch

## Run locally
```bash
npm install
npm start
```

## Production build
```bash
npm run build
```

## Deployment
The generated `build/` folder can be deployed to Vercel, Netlify or another static hosting provider. For Vercel, use the standard Create React App deployment settings.

## Image replacement
Approved company/product images should replace files referenced under `public/assets/images/`. The current website intentionally uses professional placeholders because no approved ZJ Energy product/factory photography was supplied.

Recommended filenames are documented in `public/assets/images/README.txt`.

## Important content placeholders
The About page intentionally leaves factory size and production capacity as `—` until official company figures are supplied. Do not publish invented certifications, production numbers, brands or technical specifications.

## Contact form
The contact form is front-end only. Connect it to the company's preferred email/CRM/API endpoint before production use.

## Domain
Configured public-facing domain reference: `guangdongzjenergy.com`.
